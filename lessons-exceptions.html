Intermediate / Exception Handling

Exception Handling

Error aane par program crash na ho — usko "handle" karo

Abhi tak jab error aata tha, program wahin ruk jata tha (crash). Real apps mein ye nahi chalta — agar ek user galat input de, to poora program band nahi hona chahiye. Isliye try / except use karte hain.

Basic try-except

try: age = int(input("Apni age batao: ")) print("Agle saal tum", age + 1, "ke ho jaoge") except: print("Ye valid number nahi tha!")

try ke andar wo code likho jisme error aa sakta hai. Agar error aaya, program crash nahi hoga — seedha except block chal jayega.

Specific error catch karo

Better practice hai specific error ka naam batana (jo humne Error Dictionary mein seekha):

try: result = 10 / 0 except ZeroDivisionError: print("Zero se divide nahi ho sakta!") except ValueError: print("Value sahi nahi thi!")
💡 Har error ke liye alag except rakhna better hai kyunki tumhe pata chalta hai exact kya problem hui — sirf "kuch error aaya" jaanna kaafi nahi hota.

finally — hamesha chalta hai

finally block error aaye ya na aaye, hamesha chalta hai — cleanup jaise kaam ke liye useful (jaise file close karna):

try: print("Kaam ho raha hai") result = 10 / 0 except ZeroDivisionError: print("Error pakda gaya") finally: print("Ye hamesha chalega")
