Data Types

Har variable ke andar rakhi cheez ka ek "type" hota hai

Pichle lesson mein humne variables banaye. Ab dekhte hain ki un variables ke andar konsi type ki value store ho sakti hai. Python khud samajh leta hai kaunsa type hai — tumhe alag se batana nahi padta.

TypeExampleMatlab
intage = 22Whole number
floatprice = 49.99Decimal number
strname = "Tejas"Text (string)
boolis_done = TrueTrue ya False
listskills = ["Python","SQL"]Multiple values ek jagah
dictuser = {"name":"Tejas"}Key-value pairs

Type check karo

Confuse ho ki kaunsa type hai? type() function use karo:

age = 22 print(type(age)) # <class 'int'>
💡 Ye samajhna zaroori hai kyunki agle lesson ("Loops") mein hum list pe kaafi kaam karenge.
