Error Dictionary

Python mein error aana normal hai — har programmer ko roz aata hai. Yahan common errors ka matlab, karan, aur fix diya hai.

SyntaxError

Code ka structure hi galat hai — jaise ek colon (:) chhoot gaya, ya bracket close nahi hua.

if age > 18 print("Adult")
Fix: if ke baad colon lagao — if age > 18:

IndentationError

Python mein spacing (indentation) se pata chalta hai konsa code kis block ke andar hai. Ye mismatch ho jaye to error aati hai.

EXAMPLE JO ERROR DETA HAI
if age > 18: print("Adult")
Fix: print line ko indent karo (4 spaces andar) — if ke andar jo bhi code hai wo indented hona chahiye.

NameError

Ek variable ya function use kiya jo pehle define hi nahi hua — ya spelling galat hai.

EXAMPLE JO ERROR DETA HAI
print(nam) # 'name' likhna tha
Fix: Variable pehle define karo, aur spelling double-check karo. Python case-sensitive hai — Name aur name alag hain.

TypeError

Do alag types ko aise combine karne ki koshish jo Python allow nahi karta — jaise number aur text ko directly jodna.

EXAMPLE JO ERROR DETA HAI
age = 22 print("Age hai: " + age)
Fix: Number ko string mein convert karo — str(age) use karo, ya f-string: f"Age hai: {age}"

ValueError

Type sahi hai, but value convert nahi ho sakti — jaise text ko number mein convert karne ki koshish jab text actually number nahi hai.

EXAMPLE JO ERROR DETA HAI
age = int("bees") # 'bees' number nahi hai
Fix: Convert karne se pehle check karo ki value valid number-jaisi hai ya nahi (jaise .isdigit() se).

IndexError

List mein jo position (index) maangi wo exist hi nahi karti.

EXAMPLE JO ERROR DETA HAI
skills = ["Python", "SQL"] print(skills[5]) # sirf 2 items hain (index 0,1)
Fix: Yaad rakho list ki length se pehle index rukta hai — len(skills) se check kar sakte ho, ya skills[-1] se last item milega.

KeyError

Dictionary mein jo key maangi wo exist nahi karti.

EXAMPLE JO ERROR DETA HAI
user = {"name": "Tejas"} print(user["age"]) # 'age' key hai hi nahi
Fix: .get() use karo — user.get("age", "Not set") — agar key na mile to error nahi, default value milegi.

AttributeError

Kisi object pe aisa method/function call kiya jo us type ke paas hota hi nahi.

EXAMPLE JO ERROR DETA HAI
age = 22 age.upper() # numbers ke paas 'upper' nahi hota, strings ke paas hota hai
Fix: Check karo variable ka type kya hai (type(age)) aur us type ke sahi methods use karo.

ZeroDivisionError

Kisi number ko 0 se divide karne ki koshish — math mein ye possible hi nahi hai.

EXAMPLE JO ERROR DETA HAI
result = 10 / 0

ModuleNotFoundError

Jo library/module import karne ki koshish ki wo installed hi nahi hai tumhare system pe.

EXAMPLE JO ERROR DETA HAI
import requests # agar requests installed nahi hai
Fix: Terminal mein install karo — pip install requests — phir dobara run karo.
