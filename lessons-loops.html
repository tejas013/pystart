Loops

Repeat a task multiple times with Python loops.

For Loop

A for loop is used when you want to repeat code for each item in a sequence.

for i in range(5):
    print(i)

This prints numbers from 0 to 4.

While Loop

A while loop keeps running as long as its condition is True.

count = 0

while count < 5:
    print(count)
    count = count + 1
Warning: Make sure the condition eventually becomes False, otherwise you can create an infinite loop.

Loop Through a List

You can use a for loop to process every item in a list.

skills = ["Python", "SQL", "Excel"]

for skill in skills:
    print(skill)
