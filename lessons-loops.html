Loops

Ek kaam baar-baar karwana ho to loop use karo

Socho tumhe 1 se 5 tak print karna hai. Bina loop ke tumhe 5 baar print() likhna padega. Loop se ek hi line mein ho jayega — "jab tak condition sahi hai, ye kaam karte raho."

for loop — jab pata ho kitni baar

for loop tab use karo jab pata ho kitni baar repeat karna hai — jaise list ke har item pe ya fixed number of times.

for i in range(5): print(i) # Output: 0 1 2 3 4

range(5) ka matlab hai 0 se 4 tak 5 numbers. Python mein counting 0 se shuru hoti hai, ye bahut students ko confuse karta hai — yaad rakho.

while loop — jab tak condition sahi hai

while loop tab use karo jab pata na ho kitni baar chalega — bas ek condition di jaati hai.

count = 0 while count < 3: print("Count hai:", count) count = count + 1
⚠️ Sabse common mistake: while loop mein agar tum count = count + 1 likhna bhool jao, to loop kabhi khatam nahi hoga (infinite loop). Agar code atak jaye, ye pehle check karo.

List ke saath for loop

Ye sabse zyada use hone wala pattern hai — kisi list ke har item pe kuch karna:

skills = ["Python", "SQL", "Excel"] for skill in skills: print("Main seekh raha hoon:", skill)
