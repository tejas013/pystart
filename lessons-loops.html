Loops

Ek kaam baar-baar karwana ho to loop use karo.

For Loop

A for loop repeats code for each item in a sequence.

for i in range(5): print(i)

While Loop

A while loop keeps running while its condition is True.

count = 0 while count < 5: print(count) count = count + 1
Warning: Make sure the condition eventually becomes False, otherwise you can create an infinite loop.

Loop Through a List

You can use a for loop to process every item in a list.

skills = ["Python", "SQL", "Excel"] for skill in skills: print(skill)
