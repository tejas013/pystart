Variables

Data ko store karne ka sabse pehla tarika

Variable ek naam ka dabba (box) hai jisme tum kuch bhi store kar sakte ho — number, text, list, kuch bhi. Python mein variable banane ke liye kisi special keyword ki zarurat nahi — bas naam do aur value assign karo.

name = "Tejas" age = 22 is_student = True

Yahan name, age, aur is_student — teeno variables hain. = sign ka matlab hai "iski value ye set karo", math wala "barabar" nahi.

Rules yaad rakho

1. Variable naam number se shuru nahi ho sakta (2name galat hai)
2. Space nahi rakh sakte — underscore use karo (student_name)
3. Python case-sensitive hai — Age aur age alag variables hain

💡 Tip: Variable ka naam aisa rakho jo padhte hi samajh aa jaye kya store hai andar — x ki jagah student_age likho.
