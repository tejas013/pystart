Project: Calculator

Ek real working calculator — same logic jo tumne Conditionals aur Functions lesson mein seekhi, bas ab ek button dikhne wali app mein.

0

Ye kaam kaise karta hai

Poori calculator ka logic ek hi function mein hai — calculate(). Ye display mein jo text hai (jaise "12+5") usko leta hai aur JavaScript ke built-in eval() se calculate karta hai.

function calculate() { try { display.value = eval(display.value); } catch { display.value = "Error"; } }

Dekha? Yahi try/except wala pattern hai jo tumne Exception Handling lesson mein seekha — JS mein isko try/catch kehte hain, kaam bilkul same hai: agar calculation galat ho (jaise 5//), crash hone ki jagah "Error" dikha do.

Buttons aur functions ka connection

Har button ek function call karta hai — onclick="appendValue('7')" ka matlab hai "click hone par appendValue function ko 7 bhejo." Ye bilkul waisa hi hai jaise Python mein greet("Tejas") likh ke function ko value bhejte hain.

💡 Isi tarah se real apps banti hain — chhote functions jo ek-ek kaam karte hain (add karna, clear karna, delete karna), aur buttons unhe trigger karte hain.

Try karo

Upar calculator use karo — kuch galat bhi try karo (jaise sirf "+" dabao aur "=" dabao) — dekho "Error" kaise handle hota hai crash ki jagah.
