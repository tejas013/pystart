OOP Basics

Real-world cheezon ko code mein represent karna

Ab tak humne functions banaye jo ek kaam karte hain. Ab ek naya idea — class. Class ek "blueprint" hai jisse tum apna khud ka data-type bana sakte ho — jaise "Student", "Car", "BankAccount" — jisme apni properties aur khud ke functions ho.

Class aur Object

Class ek blueprint hai, object uska actual instance. Jaise "Car" ek blueprint hai, but tumhari specific car (red color, Honda) ek object hai.

class Student: def __init__(self, name, age): self.name = name self.age = age def introduce(self): print("Main", self.name, "hoon, umar", self.age) s1 = Student("Tejas", 22) s1.introduce()

__init__ kya hai?

__init__ ek special function hai jo object banate hi automatically chalta hai — isme tum decide karte ho ki naya object banate waqt kya-kya values chahiye (yahan name aur age).

self kya hai?

self matlab "ye wala object khud." Jab tum self.name = name likhte ho, to iska matlab hai "is specific object ke andar name store karo." Har method ka pehla parameter self hota hai — Python isko automatically pass kar deta hai, tumhe manually dena nahi padta.

💡 Simple tarike se socho: class ek "form" hai, object har person ka bhara hua form. self matlab "is particular form ki baat kar rahe hain."

Multiple objects

s1 = Student("Tejas", 22) s2 = Student("Riya", 21) s1.introduce() s2.introduce()

Dono objects apna alag name aur age rakhte hain — same class se banaye, but data alag-alag.
