Conditionals

Let your code make decisions using conditions.

Every program needs to make decisions. Python uses if, elif, and else to control what happens when a condition is true or false.

Basic if-else

age = 20

if age >= 18:
    print("You can vote")
else:
    print("You cannot vote yet")

Indentation, or spaces at the beginning of a line, is very important in Python. Code inside an if block must be indented.

Multiple Conditions — elif

Use elif when you need to check more than two possible conditions.

marks = 72

if marks >= 90:
    print("Grade A")
elif marks >= 75:
    print("Grade B")
elif marks >= 60:
    print("Grade C")
else:
    print("Fail")

Python checks conditions from top to bottom. As soon as it finds a condition that is True, that block runs and the remaining conditions are skipped.
