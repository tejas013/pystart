Functions

Reusable blocks of code that keep your programs clean and organized.

A function is a named block of code that you can call whenever you need it. This makes your code shorter, cleaner, and reusable.

Create and Call a Function

def greet(name):
    print("Hello,", name)

greet("Tejas")
greet("Riya")

def is used to define a function. name is a parameter that receives a value when the function is called.

return — Send a Value Back

print() displays something on the screen. If you want to use a function's result later, use return.

def add(a, b):
    return a + b

result = add(5, 3)
print(result)   # 8
Tip: print() displays a value, while return sends a value back so it can be stored or used elsewhere in your program.

Default Parameters

You can give a parameter a default value that is used when no value is provided.

def greet(name="Student"):
    print("Hello,", name)

greet()          # Hello, Student
greet("Tejas")   # Hello, Tejas
